# Posture Check

A RuneLite plugin that reminds you to correct your posture during long play sessions.

## Build

```bash
gradle build
```

## Local Development

1. Open this folder in your IDE (IntelliJ or VS Code).
2. Ensure Java 11+ is installed.
3. Follow the [RuneLite plugin development guide](https://github.com/runelite/runelite/wiki/Building-with-IntelliJ-IDEA) to set up the dev environment and launch the client with your plugin.

## Config

- **Reminder interval**: How often to remind you (minutes, default 30)
- **Reminder text**: Custom notification text
- **Notifications**: Toggle notifications on/off
